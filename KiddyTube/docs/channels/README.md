**Rating scale used in dossiers**

- **Suggested rating:** preschool / TV-Y style (informal; not a formal board rating)
- **Clean language:** High / Medium / Low
- **Violence / scary:** None / Low / Medium
- **Conservative / family fit:** High / Medium–High / Medium (how well it fits a cautious Muslim / conservative household)
