# Deploy KiddyTube Cloud on Render + Neon

Family catalog admin + device pairing API, hosted for free (with cold starts).

## 1. Neon (Postgres)

1. Sign up at [https://neon.tech](https://neon.tech) → **Create project** (e.g. `kiddytube`).
2. Open **Connection details** → copy the URI (include `?sslmode=require`).
   - Example shape:  
     `postgresql://user:pass@ep-….aws.neon.tech/neondb?sslmode=require`
3. Keep this private — you’ll paste it into Render as `DATABASE_URL`.

Optional local test against Neon:

```bash
cd cloud
cp -n .env.example .env
# set DATABASE_URL to the Neon URI
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8787
```

The app rewrites `postgresql://` → `postgresql+psycopg://` automatically.

## 2. Render (API + admin website)

### Option A — Blueprint (recommended)

1. Push this repo to GitHub (branch with `render.yaml` + `cloud/`).
2. [Render](https://render.com) → **New** → **Blueprint** → select the repo.
3. Apply `render.yaml` (service `kiddytube-cloud`, root dir `cloud`).
4. Fill **sync: false** env vars when prompted:

| Variable | Value |
|---|---|
| `ADMIN_EMAIL` | your login email |
| `ADMIN_PASSWORD` | strong password (not the app PIN) |
| `DATABASE_URL` | Neon connection string (with `sslmode=require`) |
| `PUBLIC_BASE_URL` | leave blank until first deploy, then set to `https://<your-service>.onrender.com` |

`SECRET_KEY` can be auto-generated by Render.

5. Deploy. When live, set `PUBLIC_BASE_URL` to the service HTTPS URL and **Manual Deploy** once more.

### Option B — Manual Web Service

1. **New** → **Web Service** → this repo.
2. Root directory: `cloud`
3. Runtime: Python  
   Build: `pip install -r requirements.txt`  
   Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Same env vars as above.
5. Health check path: `/health`

## 3. Verify

- Admin: `https://<your-service>.onrender.com/admin`
- Health: `https://<your-service>.onrender.com/health` → `{"ok":true}`
- Log in with `ADMIN_EMAIL` / `ADMIN_PASSWORD`
- **Devices → Generate pairing code**

## 4. Point the apps at Render

On each TV / iPad:

1. Parent unlock → **Home & Sync**
2. **Cloud server URL** → `https://<your-service>.onrender.com`  
   (no trailing slash)
3. **Pair device** with the 6-digit code from admin
4. **Pull catalog from cloud**

After that, edit catalog on the website → **Pull catalog** on devices (or wait for the daily pull).

## Free-tier notes

- **Render free** web services **sleep** after idle (~15 min). First request after sleep can take 30–60s — that’s normal.
- **Neon free** may suspend compute when idle; first query wakes it (Render’s `pool_pre_ping` helps).
- For a smoother kid experience later: upgrade Render to a cheap always-on plan, or hit `/health` on a schedule (e.g. UptimeRobot every 10 min).

## Security checklist

- [ ] Strong `ADMIN_PASSWORD` and `SECRET_KEY`
- [ ] Never commit `.env` or Neon passwords
- [ ] Prefer HTTPS only (`PUBLIC_BASE_URL` with `https://`)
- [ ] Revoke lost devices in Admin → Devices
